# Security and Safety

Whiteout is a defensive DFIR challenge project.

- Use only isolated systems owned or explicitly authorized by the author.
- Use fictional organizations, accounts, servers and documents.
- Never include real credentials, secrets, customer records or personal information.
- Do not include functional malware or destructive payloads.
- Generate activity in disposable lab systems.
- Preserve artifact integrity with SHA-256 and provenance.
- Keep author answers and write-ups private until publication rules permit disclosure.
