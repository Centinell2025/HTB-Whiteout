# Private Author Write-up — Whiteout

For every scored answer include:
1. question;
2. exact answer;
3. artifact/source;
4. timestamp in UTC;
5. parsing/analysis method;
6. corroborating evidence;
7. classification: ENVIRONMENTAL / BENIGN-ADMIN / MALICIOUS / UNKNOWN;
8. why alternative explanations were rejected.

Do not finalize until the evidence package is frozen and hashed.
