# Candidate Scored Questions — Whiteout

1. What was the first confirmed infrastructure degradation event?
2. Which server first lost reliable centralized telemetry?
3. What was the first server with evidence of suspicious local activity?
4. Which identity was involved in the first suspicious authentication?
5. Was that authentication consistent with the storm recovery schedule?
6. Which event demonstrates a legitimate VPN or gateway failure?
7. Which event cannot be explained by communications degradation?
8. Which server-to-server transition is the first defensible sign of lateral movement?
9. What evidence shows that a central SOC gap did not equal host inactivity?
10. Which process or administrative mechanism executed during the visibility gap?
11. Was the backup failure environmental, malicious, or mixed?
12. Identify the strongest evidence of unauthorized activity on BACKUP-SRV-01.
13. Was persistence established? If so, where and by what mechanism?
14. Which FILE-SRV-02 activity occurred while centralized visibility was impaired?
15. Identify the fictional data or audit material prepared for collection/staging.
16. Which timestamps represent event occurrence versus delayed ingestion?
17. Reconstruct the correct server sequence.
18. Identify two events initially attributable to the storm that were actually benign recovery actions.
19. Identify two events that were malicious despite occurring during the outage.
20. Provide the final incident conclusion: environmental failure only, cyberattack only, or combined event — and justify it with independent evidence.
